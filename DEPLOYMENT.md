# Production Deployment Guide (Vercel & Cloud Database)

This document provides step-by-step instructions for deploying the **Blogify** application to production on **Vercel** with a managed PostgreSQL database (Neon, Supabase, or AWS RDS).

---

## Architecture Overview

- **Frontend & Edge API Routes**: Next.js 16 (Turbopack, App Router) hosted on Vercel Edge/Serverless Infrastructure.
- **Database & ORM**: PostgreSQL database connected via Prisma ORM (`prisma/schema.prisma`).
- **Authentication**: NextAuth.js JWT-based session strategy with HTTP-only cookies and bcrypt password encryption.
- **Security & Headers**: Strict Content Security Policy (CSP), anti-clickjacking (`X-Frame-Options: DENY`), strict transport security (HSTS), and MIME protection configured in `vercel.json`.

---

## 1. Prerequisites

1. A [Vercel](https://vercel.com) account.
2. A managed cloud PostgreSQL database (e.g. [Neon Serverless Postgres](https://neon.tech), [Supabase](https://supabase.com), or [Render Postgres](https://render.com)).
3. GitHub repository access for continuous deployment.

---

## 2. Environment Variables Configuration

Set the following environment variables in your Vercel Project Settings under **Settings > Environment Variables**:

| Variable | Required | Description | Example |
| :--- | :---: | :--- | :--- |
| `DATABASE_URL` | **Yes** | Connection string for your managed PostgreSQL database. | `postgresql://user:password@ep-host.pooler.neon.tech/blogify?sslmode=require` |
| `NEXTAUTH_SECRET` | **Yes** | 32+ character random string for signing and encrypting session JWTs. | Generate with: `openssl rand -base64 32` |
| `NEXTAUTH_URL` | **Yes** | The canonical public URL of your deployed application. | `https://blogify.yourdomain.com` or `https://blogify.vercel.app` |

---

## 3. Database Schema Migration

Before launching or during the first build, push the Prisma schema to your remote production database:

```bash
# Apply schema to production database
npx prisma db push

# (Optional) Seed initial administrator and default categories
npx prisma db seed
```

Default credentials generated by `prisma/seed.ts`:
- **Administrator**: `admin@example.com` / `Admin123!`
- **Reader 1**: `jane@example.com` / `Reader123!`
- **Reader 2**: `alex@example.com` / `Reader123!`

---

## 4. Vercel Project Configuration

When importing your GitHub repository into Vercel:
1. **Framework Preset**: Select `Next.js`.
2. **Root Directory**: `./` (Root of the repository).
3. **Build Command**: `prisma generate && next build` (automatically picked up from `vercel.json`).
4. **Output Directory**: `.next` (default).
5. **Install Command**: `npm ci` (default).
